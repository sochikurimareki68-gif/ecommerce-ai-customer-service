# 电商 AI 智能客服系统 · 优眠小助手

> 基于扣子 Coze 搭建的电商智能客服智能体，通过**六路条件判断工作流**按用户意图路由，结合 FAQ 知识库与商品目录，实现商品咨询、洗护指南、物流发货、退换售后、优惠活动等场景的自动应答。

## 功能

- **六路意图路由**：意图识别节点自动分类，路由到对应分支处理
- **知识库问答（RAG）**：基于 FAQ 知识库（50条）+ 商品目录（20款）检索回答
- **多轮对话**：支持上下文追问（如"那红色的呢？"），调用工作流前自动补全完整问题
- **分级消息处理**：问候语/转人工/结束语直接回复，业务咨询走工作流，异常走安全兜底
- **安全兜底**：无法回答时礼貌引导转人工，不编造答案、不冒充人工客服

## 工作流架构

```
用户消息
   │
   ▼
意图识别（选择器节点）
   │
   ├─ ① 商品咨询 ──→ 知识库检索（FAQ+商品目录）─→ LLM 生成回复
   ├─ ② 洗护指南 ──→ 知识库检索（FAQ洗护类）──→ LLM 生成回复
   ├─ ③ 物流发货 ──→ 知识库检索（FAQ物流类）──→ LLM 生成回复
   ├─ ④ 退换售后 ──→ 知识库检索（FAQ退换类）──→ LLM 生成回复
   ├─ ⑤ 优惠活动 ──→ 知识库检索（FAQ优惠类）──→ LLM 生成回复
   └─ ⑥ 其他兜底 ──→ 安全兜底（不检索）────→ LLM 生成回复
   │
   ▼
代码节点（合并六路输出为单一 reply）
   │
   ▼
结束节点返回 reply
```

## 技术栈

- 平台：扣子 Coze（www.coze.cn）
- 工作流：选择器节点（意图识别）+ 大模型节点 + 代码节点（Python）
- 知识库：RAG 检索增强（文本知识库，按需调用）
- 模型：豆包 2.0 pro
- 前端：HTML / CSS / JavaScript
- 部署：GitHub Pages

## 实施步骤

1. 在扣子创建智能体，配置人设 Prompt（角色/语气/消息优先级/工作流调用规则等）
2. 整理 50 条电商客服 FAQ + 20 款商品目录，上传至知识库
3. 设计六路条件判断工作流：意图识别 → 六条分支 → 代码合并 → 返回
4. 配置变量与多轮对话，设置消息处理优先级
5. 测试 25 组对话用例，覆盖六大意图，记录 BadCase 并优化
6. 编写 HTML 前端页面，提供在线体验入口
7. 发布智能体并部署到 GitHub Pages
