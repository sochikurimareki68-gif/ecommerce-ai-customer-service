## 判定口径

- **答对**：末句命中预期值（如尾号 3829、床型 1.8 米），且无编造 —— 达标
- **明确说没记住**：回复明确表示没有记录/记不清 —— 达标，不逼模型硬猜
- **编造**：出现错误值（如别的尾号、别的床型）—— 失败
- **跑题**：既没答对也没承认没记住 —— 失败
- **泄漏**：回复出现 `SLOTS_JSON` 或裸 JSON —— 失败
