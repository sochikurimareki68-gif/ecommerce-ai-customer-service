## 二、意图识别节点（扣子选择器节点）

扣子的选择器节点自带LLM意图识别功能，无需单独的LLM分类节点+Switch节点。

### 输入
```
query = {{user_message}}
```

### 系统提示词
```
你是优眠家居客服的意图识别器。请根据用户消息判断属于以下哪类意图：商品咨询、洗护指南、物流发货、退换售后、优惠活动、其他。
```

### 6条意图匹配选项

| 选项 | 填写内容 |
|------|---------|
| 选项1 | 用户咨询商品材质、尺寸、颜色、款式、价格、推荐、对比等商品相关问题 |
| 选项2 | 用户询问床品清洗、保养、晾晒、缩水、起球等洗护方式问题 |
| 选项3 | 用户询问发货时间、快递公司、运费、包邮、到货时间等物流问题 |
| 选项4 | 用户要求退货、换货、退款、维修、投诉等售后服务问题 |
| 选项5 | 用户询问满减、优惠券、折扣、会员、积分、活动等优惠问题 |
| 选项6（默认） | 其他意图 |

## 五、代码节点（合并+格式化）

### 处理逻辑
6条分支只有1条会产生回复，其余为空。代码节点取非空值输出。

### 输入参数

| 参数名 | 来源 |
|--------|------|
| `output` | 分支①商品咨询LLM输出 |
| `output1` | 分支②洗护指南LLM输出 |
| `output2` | 分支③物流发货LLM输出 |
| `output3` | 分支④退换售后LLM输出 |
| `output4` | 分支⑤优惠活动LLM输出 |
| `output5` | 分支⑥其他兜底LLM输出 |

### 代码（Python）
```python
async def main(args: Args) -> Output:
    params = args.params
    outputs = [
        params.get('output', ''),
        params.get('output1', ''),
        params.get('output2', ''),
        params.get('output3', ''),
        params.get('output4', ''),
        params.get('output5', '')
    ]
    reply = ''
    for o in outputs:
        if o:
            reply = o
            break
    # 格式化检查
    if reply and '我是人工客服' in reply:
        reply = reply.replace('我是人工客服', '我是AI智能客服')
    if reply and len(reply) > 800:
        reply = reply[:800] + '...'
    return {'reply': reply}
```

### 输出
```
reply = 非空分支的回复内容（经过格式化）
```

## 七、会话记忆设计

| 记忆项 | 保留轮数 | 用途 |
|--------|---------|------|
| 最近5轮对话 | 5 | 多轮追问时理解上下文 |
| `last_product` | 整个会话 | 用户说"那红色的呢"时知道在问哪个商品 |
| `last_intent` | 1 | 连续提问时判断是否同一话题 |
| `order_id` | 整个会话 | 如果用户报过订单号，后续可用 |

### 多轮对话示例
```
用户：1.5米的床选什么规格？
AI：亲~ 1.5米床建议选被套200×230cm的规格...

用户：那红色的有吗？          ← 继承上文"1.5米床品套件"
AI：亲~ 1.5米床品套件有经典白色和雾霾蓝可选...

用户：多少钱？                ← 继续问同一商品
AI：亲~ 1.5米四件套参考价299-599元...
```

## 八、在扣子中的搭建步骤

### 8.1 创建工作流
1. 在智能体编辑页，找到「工作流」或「Workflow」
2. 点「+ 新建工作流」
3. 名称：优眠客服条件判断工作流
4. 描述：6路条件判断，按意图路由到不同知识库

### 8.2 添加节点
按顺序添加以下节点：

| 顺序 | 节点类型 | 名称 | 作用 |
|------|---------|------|------|
| 1 | LLM | 意图分类 | 把用户消息分成6类 |
| 2 | Switch | 条件判断 | 根据6类走不同分支 |
| 3 | 知识库检索×5 | 各分支检索 | 每个分支查不同知识库 |
| 4 | LLM×6 | 各分支回复 | 每个分支生成回复 |
| 5 | 代码/格式化 | 回复格式化 | 统一语气和格式 |
| 6 | 输出 | 最终输出 | 回复用户 |

### 8.3 连线
```
开始 → 意图分类 → 条件判断
                        ├→ 商品分支(检索→LLM) ──→ 格式化 → 输出
                        ├→ 洗护分支(检索→LLM) ──→ 格式化 → 输出
                        ├→ 物流分支(检索→LLM) ──→ 格式化 → 输出
                        ├→ 退换分支(检索→LLM) ──→ 格式化 → 输出
                        ├→ 优惠分支(检索→LLM) ──→ 格式化 → 输出
                        └→ 兜底分支(LLM) ──────→ 格式化 → 输出
```

搭建完成后，在扣子的工作流测试区域输入以下测试用例：
