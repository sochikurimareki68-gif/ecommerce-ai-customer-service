# 工作流设计文档

## 整体流程图

```
用户输入
    │
    ▼
┌──────────────┐
│  意图识别节点  │
└──────┬───────┘
       │
       ├── 商品咨询 ──→ 知识库检索节点 ──→ 回复用户
       │
       ├── 物流查询 ──→ 查询物流信息 ──→ 回复用户
       │
       ├── 退换货 ────→ 确认订单 ──→ 引导申请售后
       │
       ├── 投诉/纠纷 ─→ 安全兜底 ──→ 引导转人工
       │
       └── 其他/模糊 ─→ 追问用户 ──→ 重新识别
```

## 节点详细设计

### 节点1：意图识别
- **输入**：用户消息
- **处理**：使用 LLM 分类用户意图
- **分类**：
  - `product_consult`：商品咨询（材质、尺寸、颜色、款式）
  - `care_advice`：洗护咨询（怎么洗、怎么保养）
  - `logistics`：物流查询（发货、快递、运费）
  - `return_exchange`：退换货（退货、换货、退款）
  - `promotion`：优惠咨询（满减、优惠券、会员）
  - `complaint`：投诉/纠纷
  - `other`：其他/无法识别
- **输出**：意图标签 + 原始消息

### 节点2：知识库检索
- **触发条件**：意图为 `product_consult` 或 `care_advice`
- **输入**：用户消息
- **处理**：从 FAQ 知识库中检索相关内容
- **输出**：检索到的 FAQ 内容（Top 3）

### 节点3：物流查询
- **触发条件**：意图为 `logistics`
- **输入**：用户消息 + 订单信息（如有）
- **处理**：如果用户提供了订单号，查询物流；否则引导用户查看订单页
- **输出**：物流信息或引导文案

### 节点4：退换货引导
- **触发条件**：意图为 `return_exchange`
- **输入**：用户消息
- **处理**：确认退换货类型，引导用户在订单页申请售后
- **输出**：退换货流程引导文案

### 节点5：安全兜底
- **触发条件**：意图为 `complaint` 或知识库无匹配
- **输入**：用户消息
- **处理**：礼貌引导转人工客服
- **输出**："这个问题需要帮您转接人工客服..."

### 节点6：追问
- **触发条件**：意图为 `other` 或用户问题模糊
- **输入**：用户消息
- **处理**：追问用户具体需求
- **输出**："请问您想了解哪方面的信息呢？比如商品材质、洗护方式、发货物流等"

## 变量配置

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `user_intent` | string | 用户意图标签 |
| `session_memory` | object | 会话记忆（最近5轮对话） |
| `last_product` | string | 上次提到的商品（用于多轮追问） |
| `order_id` | string | 用户提供的订单号（如有） |

## 会话记忆设计

- 记忆最近 5 轮对话
- 关键信息提取：如用户提到"1.5米的床"，后续追问时记住这个尺寸
- 用户说"那红色的呢？" → 根据 `last_product` 理解为问同一商品的红色款
