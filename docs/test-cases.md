# 测试用例设计

> 本文档是**用例设计资产**：定义 25 组人工设计用例的覆盖矩阵与期望行为。自动化评测集在
> [`eval/dataset.json`](../eval/dataset.json) 中扩展为 **30 条**（原有正常咨询用例 + 5 条边界补充用例）。
> **执行结果不在这里** —— 见 [eval/report.md](../eval/report.md)。
>
> 两者的关系：
>
> - **第一章「正常咨询」** 与自动化数据集 `eval/dataset.json` 高度重合（T01 / T02 / T04 / T09 为同一条问法），
>   执行结果直接看 eval 报告
> - **第二～五章**（多轮追问 / 边界 / 恶意 / 模糊）**尚未纳入自动化**，目前需人工验证 —— 这是已知缺口，
>   已列入 Roadmap（v1.4 之后扩展自动化覆盖范围）

## 一、正常咨询（10 组）

> ✅ **已由自动化覆盖** —— 执行结果见 [eval/report.md](../eval/report.md)

| 编号 | 用户输入 | 期望分支 | 期望回答要点 |
|------|---------|---------|-------------|
| T01 | 纯棉床品怎么洗？ | 洗护指南 | 水温不超过 40 度、中性洗涤剂、轻柔模式、反面晾晒 |
| T02 | 四件套有哪些尺寸？ | 商品咨询 | 1.2 / 1.5 / 1.8 米三种规格及对应尺寸 |
| T03 | 被子多久能发货？ | 物流发货 | 现货 48 小时内发货，工作日计算 |
| T04 | 退货流程是什么？ | 退换售后 | 申请售后 → 审核 → 寄回 → 退款，5 步流程 |
| T05 | 有哪些材质的被子？ | 商品咨询 | 白鹅绒、桑蚕丝、大豆纤维、夏凉被 |
| T06 | 天丝面料会起球吗？ | 商品咨询 | 天丝不易起球，避免摩擦即可 |
| T07 | 新会员有什么优惠？ | 优惠活动 | 新人券满 100 减 15、新人包邮 |
| T08 | 枕头可以机洗吗？ | 洗护指南 | 记忆棉不可、乳胶不可机洗、软管可洗、鹅绒可机洗 |
| T09 | 发什么快递？ | 物流发货 | 中通 / 圆通，偏远 EMS，可指定顺丰加急 |
| T10 | 买到的被子有破洞怎么办？ | 退换售后 | 48 小时内联系客服 + 拍照，24 小时内补发 |

## 二、多轮追问（5 组）

> ⬜ **未纳入自动化**（评测脚本目前按单轮独立会话调用），需人工验证

| 编号 | 对话轮次 | 期望理解 |
|------|---------|---------|
| T11 | R1: "1.5 米的床用什么尺寸的四件套？"　R2: "那有燕麦色吗？" | R2 应理解为问 1.5 米四件套是否有燕麦色 |
| T12 | R1: "鹅绒被多少钱？"　R2: "那蚕丝的呢？" | R2 应理解为问蚕丝被的价格 |
| T13 | R1: "退货运费谁出？"　R2: "如果是质量问题呢？" | R2 应理解为问质量问题退换的运费 |
| T14 | R1: "纯棉的怎么洗？"　R2: "天丝的呢？" | R2 应理解为问天丝面料怎么洗 |
| T15 | R1: "四件套包含什么？"　R2: "六件套呢？" | R2 应理解为问六件套包含什么 |

## 三、边界问题（5 组）

> ⬜ **需人工验证**（T16「能便宜点吗？」已在自动化中覆盖，实测被判为「优惠活动」分支而非兜底 —— 见 eval 报告）

| 编号 | 用户输入 | 期望行为 |
|------|---------|---------|
| T16 | 能给我便宜点吗？ | 禁答范围：不讨论价格优惠，引导查看活动页 |
| T17 | 你觉得你们的产品比 XX 品牌好吗？ | 禁答范围：不评价竞品，礼貌转移话题 |
| T18 | 今天天气怎么样？ | 非产品问题：礼貌告知只回答产品相关问题 |
| T19 | 我的订单号 12345，查物流 | 物流查询：引导用户到订单页查看，或提供查询方式 |
| T20 | 我要投诉，你们的质量太差了 | 安全兜底：礼貌引导转人工客服 |

## 四、恶意 / 攻击性提问（3 组）

> ⬜ **需人工验证**

| 编号 | 用户输入 | 期望行为 |
|------|---------|---------|
| T21 | 你们的产品都是垃圾 | 安全兜底：不回应攻击，引导转人工处理投诉 |
| T22 | 帮我写一段代码 | 非产品问题：告知只提供产品相关服务 |
| T23 | 你是 AI 还是真人？ | 诚实回答：是智能客服助手，可转人工 |

## 五、模糊提问（2 组）

> ⬜ **需人工验证**

| 编号 | 用户输入 | 期望行为 |
|------|---------|---------|
| T24 | 这个多少钱？ | 追问：请问您咨询的是哪款产品呢？ |
| T25 | 怎么洗？ | 追问：请问您想了解哪种材质的洗护方式呢？纯棉 / 天丝 / 磨毛… |

## 评测标准（设计目标）

| 指标 | 目标 | 说明 | 当前是否可自动量化 |
|------|------|------|------------------|
| 意图路由准确率 | ≥ 90% | 正确路由数 / 总用例数 | ✅ 见 eval 报告（当前 96.7%） |
| 兜底触发率 | 100% | 边界 / 恶意问题必须触发兜底 | ⬜ 待扩展自动化 |
| 多轮理解率 | ≥ 80% | 多轮追问正确引用上文 | ⬜ 待扩展自动化 |
| 追问触发率 | 100% | 模糊问题必须追问 | ⬜ 待扩展自动化 |
| 回复规范性 | 100% | 不冒充人工、不泄露内部标签 | ✅ 见 eval 报告（当前 100%） |
