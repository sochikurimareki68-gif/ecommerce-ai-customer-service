# 物流与发货

【分支】物流发货

本文件覆盖运费、包邮门槛、发货时效、偏远地区、物流查询、改地址、支付方式与延迟发货补偿。
退货运费由谁承担见「08-退换货政策」，不在本文件写。

## 物流-发货仓与时效

### 发货仓库与就近发货
- 分支：物流发货
- 常见问法：从哪里发货？有几个仓库？
- 答复：发货仓库为浙江绍兴总仓，部分爆款商品设有江苏南通前置仓，会根据收货地址就近发货。
- 适用条件：所有订单按收货地址分配发货仓。
- 数值边界：绍兴为总仓，南通前置仓只覆盖部分爆款商品。
- 例外：哪些商品从前置仓发出原文未列明（待补：前置仓覆盖的商品范围）。
- 兜底：需要指定发货仓或指定发货地时，以人工客服确认为准。

### 现货发货时效
- 分支：物流发货
- 常见问法：多久能发货？什么时候发货？是现货吗？
- 答复：现货商品通常下单后 48 小时内发货，按工作日计算；如遇特殊情况延迟发货，客服会主动通知。这里的 48 小时是发货时效，不是到达时效；我们不承诺具体到达天数，到货时间以物流实际配送为准，发货后可以在订单页查看物流。
- 适用条件：详情页标注为现货的商品。
- 数值边界：发货 48 小时内，按工作日计算；到达天数不承诺，以物流实际配送为准。
- 例外：大促期间现货商品可能延迟至 72 小时，见「大促期间发货时效」；延迟发货的补偿见「延迟发货的补偿口径」。
- 兜底：超过时效仍未发货的查询，以人工客服确认为准。

### 到货时间与时效说明
- 分支：物流发货
- 常见问法：几天能到？几天能到货？石家庄几天能到？发到成都要几天？什么时候能收到？到货要多久？多久能到？几天到货？省内几天？发货后几天到？
- 答复：不承诺具体到达天数，到货时间以物流实际配送为准。商品发货后会发送短信通知，您可以在订单详情页查看物流跟踪信息；实际送达时间受收货城市、快递路线与当地派送情况影响，城市之间会有差异。如需了解当前配送进度，建议先在订单页查看物流，物流信息会随快递揽收、中转、派送实时更新。
- 适用条件：已下单或已发货订单，咨询具体到货时间与到达时效。
- 数值边界：不承诺到达天数，不设到达时效的天数区间，一律以物流实际配送为准。
- 例外：偏远地区、大促期间、天气或交通管制等不可控因素可能影响配送进度；发货快慢分别见「现货发货时效」与「预售、定制与调货发货时效」。
- 兜底：需要估算具体到货日期、或物流长时间不更新时，以人工客服确认为准。

### 预售、定制与调货发货时效
- 分支：物流发货
- 常见问法：预售多久发货？定制款什么时候发？调货要等多久？
- 答复：预售商品以商品详情页标注的预计发货时间为准，通常 7-15 天；定制商品通常 3-5 个工作日发货；调货商品（如部分颜色缺货）通常 5-7 个工作日发货，不含节假日。
- 适用条件：预售商品、定制商品与调货商品，最终以商品详情页标注的预计发货时间为准。
- 数值边界：按商品类型分条：
  - 预售：通常 7-15 天。
  - 定制：通常 3-5 个工作日。
  - 调货：通常 5-7 个工作日。
- 例外：预售 7-15 天为自然日、含节假日；定制 3-5 个工作日与调货 5-7 个工作日均按工作日计算、不含节假日，均不承诺加急。
- 兜底：详情页未标注、需要加急或涉及调货，以人工客服确认为准。

### 大促期间发货时效
- 分支：物流发货
- 常见问法：双十一发货慢吗？大促多久发货？
- 答复：大促期间（618、双 11）发货量较大，现货商品可能延迟至 72 小时发货，具体以商品详情页和店铺公告为准。
- 适用条件：618、双 11 等大促期间下单的现货商品。
- 数值边界：可能延迟至 72 小时，与日常 48 小时不同。
- 例外：大促期间预售与定制可能顺延 3-5 个自然日，以详情页与店铺公告为准；现货延迟至 72 小时。
- 兜底：大促订单超时未发货时，以人工客服确认为准。

### 延迟发货的补偿口径
- 分支：物流发货
- 常见问法：超过承诺时间没发货有补偿吗？延迟发货怎么赔？
- 答复：因卖家原因延迟发货时，会按延迟情况提供相应补偿，具体补偿金额和形式以人工客服确认为准；如遇大促或特殊情况，以店铺公告为准。
- 适用条件：订单确属因卖家原因延迟发货。
- 数值边界：原文未给出补偿金额、补偿比例与补偿时效（待补：各延迟档位对应的补偿标准），不自行承诺赔偿金额。
- 例外：大促或特殊情况以店铺公告为准；涉及赔偿金额与责任认定时转人工。
- 兜底：补偿金额与补偿形式以人工客服确认为准。

## 物流-快递与运费

### 快递公司与指定快递
- 分支：物流发货
- 常见问法：发什么快递？可以指定快递吗？偏远地区发什么？
- 答复：普通订单发中通、圆通，按收货地自动匹配；偏远地区非大件发 EMS，覆盖新疆、西藏、内蒙古、青海、宁夏、甘肃等地区；大件商品（被芯、床垫保护套）优先发德邦，收货地在偏远地区也按德邦安排；加急订单可以补差价发顺丰。
- 适用条件：按订单类型与收货地自动匹配快递；可在下单备注中指定快递，客服会尽量安排。
- 数值边界：原文未给顺丰补差价的金额（待补：顺丰补差价标准）。
- 例外：指定快递只能尽量安排，不保证一定能指定成功。
- 兜底：需要补差价寄顺丰时，以人工客服确认为准。

### 运费与包邮规则
- 分支：物流发货
- 常见问法：包邮吗？运费多少？新疆发货吗？偏远地区怎么算运费？满 199 包邮吗？
- 答复：非偏远地区不设金额门槛包邮，包括江浙沪皖粤鲁等；偏远地区（新疆、西藏、内蒙古、青海、宁夏、甘肃等）不包邮，运费以结算页显示为准，具体可让客服帮您核算；新人首单包邮见优惠活动，偏远地区除外。
- 适用条件：按收货地区判断是否包邮；偏远地区不适用无门槛包邮。
- 数值边界：非偏远地区不设金额门槛包邮，不存在「满 199 包邮」；满 199 是满减活动门槛（满 199 减 20），见「09-优惠活动」，与包邮是两件事；偏远地区不包邮，运费以结算页显示为准，不报固定金额。
- 例外：偏远地区不包邮，也不适用新人包邮；退换货运费按「08-退换货政策」执行，本文件只答正向运费。
- 兜底：具体地址是否属于偏远地区，以人工客服确认为准。

## 物流-支付方式

### 支付方式与货到付款
- 分支：物流发货
- 常见问法：可以货到付款吗？到付可以吗？支持货到付款吗？哪些城市支持货到付款？货到付款支持哪些地区？货到付款有手续费吗？到付手续费多少？货到付款手续费是几个点？COD 手续费怎么算？
- 答复：本店全渠道只支持线上支付，不支持货到付款，也不支持到付；线上支付的具体可选方式以下单页显示为准。
- 适用条件：所有订单均通过线上支付完成，下单时在订单页选择可用的线上支付方式。
- 数值边界：不提供货到付款服务，不存在货到付款手续费。
- 例外：任何地区、任何商品均不支持货到付款或到付，也不存在到付加价。
- 兜底：用户询问货到付款或到付时，按上述口径说明暂不支持即可，无需转人工。

## 物流-查询与异常

### 物流查询方式
- 分支：物流发货
- 常见问法：我的订单到哪了？怎么查物流？快递单号在哪看？
- 答复：发货后会发送短信通知、包含快递单号，可登录订单详情页查看物流跟踪，也可以将快递单号复制到快递 100 等平台查询。
- 适用条件：已发货订单；未发货订单查不到物流信息。
- 数值边界：超过 3 天没有物流更新，需联系客服处理。
- 例外：订单详情页“物流”可直接查看并复制单号，未收到短信不影响查询；仍无单号可让客服补发或直接提供。
- 兜底：查不到单号或物流信息缺失时，以人工客服确认为准。

### 订单信息修改（改地址 / 改电话）
- 分支：物流发货
- 常见问法：地址填错能改吗？下单后可以改地址吗？手机号填错了怎么办？
- 答复：收货地址或联系电话填错需要修改时，请联系人工客服处理；能否修改以仓库是否已经发货为准，发货前由人工客服协助修改，已发货订单无法直接修改收货信息。
- 适用条件：订单尚未签收，且收件信息确实填写有误。
- 数值边界：无固定时限，以仓库是否出库为准；建议付款后尽快联系。
- 例外：已发货或已签收订单不支持直接修改地址，需转人工客服按实际情况处理。
- 兜底：无法确认是否已发货时，以人工客服查询结果为准。

### 物流长时间不更新
- 分支：物流发货
- 常见问法：物流三天没动了怎么办？是不是丢件了？
- 答复：如果超过 3 天没有物流更新，请联系客服处理；快递是否丢件需要物流公司核实，不能提前承诺，确认丢失后按售后流程处理。
- 适用条件：物流信息超过 3 天未更新。
- 数值边界：3 天。
- 例外：丢件的认定口径与赔付标准原文未给（待补：丢件赔付标准）。
- 兜底：涉及丢件认定与赔付时，以人工客服确认为准。
